## À propos de ce portfolio

Ce dépôt contient le code source du site vitrine, conçu avec [Lovable](https://lovable.dev) puis affiné manuellement.

### Fonctionnalités

- Bascule de langue FR / EN sur l'ensemble du contenu
- Thème clair / sombre avec palette dédiée, texture de grain et flou décoratif
- Halo lumineux et boutons magnétiques au survol du curseur
- Navbar qui se rétrécit et reste centrée au scroll, entièrement responsive
- Carrousel de projets réactif à la vitesse de scroll, manipulable à la souris (glisser-déposer), navigable au clavier, avec repli en défilement tactile natif sur mobile
- Vague animée en filigrane dans le pied de page

### Stack technique

- [TanStack Start](https://tanstack.com/start) — framework full-stack React (SSR)
- React 19 + TypeScript
- Tailwind CSS v4
- [Motion](https://motion.dev) (Framer Motion) pour les animations
- [Bun](https://bun.sh) comme gestionnaire de paquets et runtime

## Démarrer en local

```bash
git clone https://github.com/i-Fandresena/portfolio-ainasoa.git
cd portfolio-ainasoa
bun install
bun run dev
```

Autres scripts utiles :

```bash
bun run build     # build de production
bun run lint      # linting
bun run format    # formatage avec Prettier
```
